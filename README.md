# E-Commerce Order Management System

## Files
- `E_Commerce_Requirement_Specification.docx` — Requirement Specification document.
- `customer_database.sql` — Creates the Ecommerce database, Customer table, and inserts 10 customer records.

## How to run
Run `customer_database.sql` in your MySQL environment.

The script:
1. Creates the `Ecommerce` database.
2. Creates the `Customer` table.
3. Applies PRIMARY KEY, NOT NULL, and UNIQUE constraints.
4. Inserts 10 customer records.
5. Displays the inserted records.

## Note
The supplied task sheet lists `City` as a Customer attribute but does not specify its datatype in the datatype table. The SQL implementation uses `VARCHAR(50)` for City.
